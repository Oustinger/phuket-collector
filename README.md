# Мониторинг цен: Екатеринбург → Пхукет

Собирает минимальные цены по пяти направлениям на октябрь и ноябрь 2026 и коммитит их
в `data/`. Работает на раннере GitHub Actions — компьютер для этого не нужен.

## Что откуда берётся

| Направление | Зачем |
|---|---|
| `SVX-HKT` | прямой и стыковочные из Екатеринбурга |
| `MOW-HKT` | основной вариант — одним билетом из Москвы |
| `MOW-BKK` | первая половина связки через Бангкок |
| `BKK-HKT` | вторая половина связки |
| `SVX-MOW` | доезд до Москвы самолётом |

Источники: официальный API Travelpayouts (нужен бесплатный токен), при его отказе —
недокументированный календарь Aviasales без токена.

## Настройка

1. Получить бесплатный токен на travelpayouts.com (регистрация партнёра, раздел с API).
2. Settings → Secrets and variables → Actions → New repository secret, имя `TP_TOKEN`.
3. Actions → «Цены на билеты» → Run workflow — проверить, что первый запуск прошёл.

Без токена сборщик работает только на запасном источнике — данных будет меньше.

## Важные ограничения

**Цены за одного пассажира и без подтверждённого багажа.** Это кэш минимальных цен —
тот же, что в блоке «Цены на соседние даты» на Aviasales. Итоговую цену с багажом
на двоих проверяйте отдельно перед покупкой.

**Одно предложение на дату.** API отдаёт только самый дешёвый вариант, а не выдачу
поиска. Значит отсюда нельзя узнать ни сколько дешёвых билетов осталось, ни есть ли
на ту же дату рейс вдвое короче за чуть большие деньги. Самый дешёвый регулярно
оказывается с двумя пересадками и 30–44 часами в пути. За качеством стыковки ходит
отдельная браузерная сверка, не этот сборщик.

## Файлы

- `data/latest.json` — последний замер
- `data/history/<дата>.json` — архив по дням
